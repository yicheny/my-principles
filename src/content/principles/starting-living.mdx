# 1-1 活在当下
<QA review={1} tabs={['几个问题']} lastReview="2026-05-11">
<Fragment slot="tab0" >
1. 我是否习惯逃避现实，担心未来？我是否总是幻想梦幻般的未来？
2. 我是否会为过去的事懊恼，结果当下变得痛苦？
3. 早上起床的时候，我有没有决心 把握当下，把这24小时活到极致？
4. 我能不能 活在当下的密室中，更充分的利用生活
5. 我应当从什么时候开始改变？下个星期？明天？还是从今天开始？

# 1-2 解决烦恼局面的神奇法则
<QA review={1} tabs={['威利斯法则']} lastReview="2026-05-12">
<Fragment slot="tab0" >
遇到令你担心的问题，请按下面的3个步骤，运用威利斯 哈维兰 卡里尔（空调之父）的神奇法则：
1. 问问自己：最坏的可能是什么？
2. 万一发生了最坏的情况，做好接受它的心理准备
3. 冷静的着手改善最坏情况
</Fragment>
</QA>

# 2-2 加林-利奇菲尔德方法
<QA review={0} tabs={['加林-利奇菲尔德方法']} lastReview="2026-05-12">
<Fragment slot="tab0" >
不妨试着运用 加林-利奇菲尔德 的方法，按照以下步骤，解决你眼下的某件烦心事：
1. 我在担心什么？
2. 我能做些什么？
3. 我将采取哪些步骤？
4. 什么时候开始行动？
</Fragment>
</QA>

# 2-3 弗兰克-贝特格方法
<QA review={0} tabs={['弗兰克-贝特格方法']} lastReview="2026-05-12">
<Fragment slot="tab0" >
当你在工作中遇到烦恼的时候，不妨试试弗兰克-贝特格方法
1. 问题是什么？
2. 问题的成因是什么？
3. 有哪些措施可能解决这个问题？
4. 你建议采取何种措施？
</Fragment>
